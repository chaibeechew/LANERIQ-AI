# LANERIQ AI — Super Game Creator Knowledge V1

Canonical journey: **Idea → World → Character → Combat → Merge → Playable Game → Export**.

## 1. AI Map / World Builder
AI Map is a semantic world generator, not merely a decorative map. A world manifest contains zones, routes, spawn points, objective anchors, gameplay hooks and truth metadata. Local semantic worlds do not claim live traffic, real-time POIs or provider geodata. Provider-backed geodata must remain separately configured and evidence-gated.

## 2. Character Asset Builder
Avatar assets may become playable characters, NPCs, enemies, bosses, companions, merchants, guides, quest givers or summons. Private asset IDs must be validated against the authenticated owner before fusion. Real-person likeness continues to require consent and must not be used to infer identity or sensitive attributes.

## 3. Game Intelligence Forge
Runtime categories: Weapon, Item, Treasure, Skill, Magic, Kungfu, Ultimate, Defense, Healing, Buff, Debuff, Summon, Transformation, Character Build and Combat Balance.

Every Forge blueprint is bounded structured data: rarity, element, target, numeric formula fields, cooldown, resource cost, effects, requirements, counters, exactly ten upgrade levels, PvE/PvP tuning, optional boss variant and text briefs for animation/VFX/sound/icon generation. User-authored code/formulas are never evaluated.

Natural-language refinement supports bounded strengthening, PvP balancing, original wuxia-style transformation and boss variants. Theme transformations must remain original and must not imitate commercial characters, maps, signature moves, logos or franchise assets.

Animation/VFX/sound/icon outputs in Forge V1 are **prompts/briefs**, not claims that rendered assets already exist. Rendering happens only when a separately approved media runtime actually produces evidence.

## 4. Super Game Fusion
Fusion inputs: one owner-scoped World Manifest, zero or more owner-scoped Avatar references, zero or more owner-scoped Forge blueprints, genre/play mode and bounded game settings. Fusion compiles these inputs into the existing Professional Game Creator request. It must not bypass authentication, account verification, Professional/Full Access, Fair Use reservations, idempotency or release truth boundaries.

World topology must affect navigation, encounters, objectives, spawn/checkpoints and progression rather than being used only as wallpaper. Character references preserve authorized visual continuity. Combat blueprints become structured mechanics and balance guidance.

## 5. Output truth
Implemented target: playable LANERIQ game request through the existing runtime with Web Preview and current game target contracts. Future engine-package ambitions (Unity, Unreal, Godot, Roblox, sprite sheets and external engine APIs) are roadmap items until real exporters and validation evidence exist.

## 6. Safety and quality
- Original content only; no copied commercial IP.
- No arbitrary code execution from Forge formulas.
- Owner-scoped world, Avatar and Forge data.
- Mobile-readable telegraphs, accessible contrast and touch-first controls.
- PvP requires counterplay, bounded control durations and separate tuning.
- Live maps, online multiplayer, store approval and real-device performance remain separately evidence-gated.
