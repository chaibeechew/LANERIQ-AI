# LANERIQ AI Super Game Creator — Knowledge Addendum V1.1

Canonical production journey: **Idea → World → Character → Scene Assets → Combat → Merge → Playable Game → Export**.

## Expanded AI Map knowledge
World Builder supports city, island, fantasy, space, dungeon, battle zone, mission zone, simulation, property, business and adventure semantic worlds. Dungeon topology models room progression, puzzle/combat/loot rooms and boss gates. Mission zones model briefing, intel, optional objectives, checkpoints, hazards, primary objectives and extraction. Simulation worlds model systems, economy, capacity, population, utilities, transit, production and scenario goals.

These are semantic game/world plans. They do not claim live geospatial truth, current businesses, traffic, property boundaries or map tiles unless a separately connected provider returns verified evidence.

## Private scene/media asset fusion
Super Game Builder may reuse owner-scoped Image Studio and Asset Library image/video records as scene references. The API re-validates every selected asset against the authenticated owner and supported media category before forwarding it. Signed previews remain short-lived. Selected private assets remain private and are never converted into cross-user shared assets by fusion.

Scene references can guide environment, props, UI, mood, authorized visual continuity and presentation. They are not executable inputs. Avatar references remain separately role-aware because playable/NPC/enemy/boss/companion/merchant/guide/quest-giver/summon roles affect runtime behavior.

## Game Intelligence Forge
Forge remains bounded structured design data. Weapon, Item, Treasure, Skill, Magic, Kungfu, Ultimate, Defense, Healing, Buff, Debuff, Summon, Transformation, Character Build and Combat Balance preserve explicit numeric fields rather than executable formula strings. Level 1–10 curves, PvE/PvP splits, counterplay, Boss variants and animation/VFX/sound/icon briefs are part of the knowledge contract.

## Runtime bridge
World, Avatar, scene assets and Forge data compile into the existing Professional Game Creator gateway. This bridge must never bypass authentication, account verification, Professional/Full Access, Fair Use, idempotency, release gates or truth boundaries.

Direct Unity, Unreal Engine, Godot and Roblox package exporters remain roadmap capabilities until actual exporters and validation evidence exist.
